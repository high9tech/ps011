# HIGH TECH PS - All-in-One Jailbreak Host 🎮✨

موقع واستضافة مخصصة لتشغيل ثغرات وتعديلات أجهزة البلايستيشن (**PS4 / PS5**) أوفلاين بتصميم عصري باللون الذهبي الخالص وخلفية الشاشة الكاملة.

---

## 🌟 المميزات
* **تصميم ذهبي (Gold Theme):** واجهة فخمة ومناسبة للعرض على شاشات التلفزيون المتصلة بالكونسول.
* **خلفية شاشة كاملة (Full Screen):** عرض صورة `background.png` بتناسق كامل خلف الواجهة.
* **زر موحد (All-in-One Trigger):** تشغيل جميع الثغرات والـ Payloads (GoldHEN, PSFree, WebKit) بزر واحد ذكي.
* **دعم العمل بدون إنترنت (Full Offline Support):** يدعم التخزين المؤقت عبر `Service Worker` و `AppCache`.
